1. Executive Summary & System Overview

In the modern recruitment ecosystem, job seekers face substantial friction. Enterprise Applicant Tracking Systems (ATS) automatically filter out over 70% of resumes before a human recruiter ever sees them due to formatting glitches, lack of measurable impact metrics, and missing keyword densities. Furthermore, job seekers struggle to tailor application materials for hundreds of distinct job listings and lack objective coaching for high-stakes interviews.

AI Career Co-Pilot resolves these challenges through a unified multi-agent platform that automates the entire preparation lifecycle: from PDF resume parsing and ATS gap scoring, to vector-similarity job matching, anti-hallucination cover letter generation, and STAR-method mock interview simulations.

2. Multi-Agent Ecosystem & Agent Capabilities

The platform utilizes a collaborative Multi-Agent System (MAS) where specialized agents operate as nodes in a LangGraph state machine, reading from and writing to a shared candidate state.

Orchestrator Agent LangGraph
Coordinates cyclical graph execution, manages conditional branching (e.g., re-routing low-scoring resumes to rewrite nodes), and maintains execution history across sessions.
Resume Analysis Agent PyMuPDF + RAG
Extracts raw text, maps layout to structured profiles, and queries ChromaDB ATS knowledge bases to produce 0–100 score breakdowns with quantifiable bullet rewrites.
Semantic Job Matcher Embeddings
Generates dense vector representations of candidate resumes and target job requisitions, computing cosine similarity and generating AI reasoning fit badges.
Cover Letter & Guardrails LLM + Guardrails
Drafts tailored cover letters calibrated by role and tone, equipped with automated verification guardrails that prevent hallucinated achievements or unverified skills.
Mock Interview Coach Agent STAR Rubric Engine
Conducts turn-by-turn interview simulations tailored to target roles. Evaluates candidate answers against the STAR (Situation, Task, Action, Result) rubric and produces structured improvement feedback.

5. Technical Glossary & Core Terminologies

A reference guide to the fundamental concepts, algorithms, and architectural patterns employed across the platform:

Multi-Agent System (MAS)
A software architecture where autonomous specialized agents handle distinct sub-tasks, communicating through shared state and message passing rather than a monolithic prompt.
LangGraph & StateGraph
A graph-based coordination framework where computational nodes represent agents or tools and edges define execution flow, conditional routing, and state persistence.
Retrieval-Augmented Generation (RAG)
Enhancing language model prompts by dynamically fetching authoritative context (ATS guidelines) from a vector database before generating scoring and rewrites.
Vector Embeddings
High-dimensional mathematical representations of text where semantically similar phrases are mapped closer together in geometric vector space.
Cosine Similarity
A mathematical metric measuring the cosine of the angle between two embedding vectors, yielding a score from 0.0 to 1.0 to quantify resume-to-job relevance.
Applicant Tracking System (ATS)
Automated enterprise recruitment software that parses, indexes, and ranks candidate resumes based on strict keyword matching and document readability.
Anti-Hallucination Guardrails
Programmatic verification checks that compare generated text (e.g., cover letters) against source resume facts to prevent invented claims or metrics.
Server-Sent Events (SSE)
A unidirectional HTTP streaming standard allowing the backend to push real-time agent execution events and telemetry to client web browsers over a single connection.
STAR Behavioral Interview Method
A structured interviewing model evaluating answers across four core components: Situation (context), Task (responsibility), Action (specific steps taken), and Result (quantified impact and business outcome).
