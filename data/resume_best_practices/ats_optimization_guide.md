# ATS Optimization & Resume Best Practices Guide

## 1. Structure & Formatting Standards
- Use standard single-column layouts for maximum parser compatibility.
- Clear section headings: Summary, Core Competencies / Technical Skills, Professional Experience, Education, Certifications.
- Chronological ordering for professional experience (Role, Company, Location, Dates).
- Avoid tables, multi-column text boxes, headers/footers containing core contact information, and non-standard icons.

## 2. Impact Bullet Formula (XYZ / STAR)
- Every bullet should follow the Google XYZ formula: "Accomplished [X] as measured by [Y], by doing [Z]".
- Begin every bullet with a strong action verb (e.g., *Architected, Spearheaded, Engineered, Optimized, Streamlined, Reduced*).
- Include numerical impact metrics: percentage improvements, dollar values, user volume, RPS throughput, latency reductions.

## 3. Skill Matching & Keyword Density
- Directly mention primary technologies, frameworks, and architecture patterns specified in the target job description.
- Categorize technical skills: Languages, Frameworks, Cloud & DevOps, Databases, AI & ML Tools.
- Contextualize skill usage in actual bullets rather than only in an isolated skills list.
