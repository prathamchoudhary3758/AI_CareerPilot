# STAR Method & Impact Metric Guidelines

## Situation, Task, Action, Result Framework
1. **Situation**: Specify the business context, engineering challenge, or legacy bottleneck.
2. **Task**: Define the explicit objective, target SLA, or deliverable.
3. **Action**: Articulate the specific tools, algorithms, or architectural patterns chosen (e.g. LangGraph state routing, FastAPI async handlers, Redis caching).
4. **Result**: Deliver measurable outcomes (e.g., 42% latency reduction, 10M+ daily events processed with 99.99% uptime).

## Strong Action Verbs vs Weak Verbs
- Weak: *Assisted with, Worked on, Handled, Responsible for, Helped with*
- Strong: *Spearheaded, Architected, Automated, Benchmarked, Eliminated, Modernized, Refactored, Accelerated*
